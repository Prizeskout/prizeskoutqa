Introduction

PrizeSkout is the middleware layer that keeps a merchant's storefront prices in margin-safe sync across regional delivery networks. You integrate once; the platform handles ingestion, evaluation, outbound execution, and a signed compliance ledger.

The API is organized around four primitives, each documented below with runnable examples in Node.js (TypeScript), Python 3.10+, and raw cURL.

PrimitiveEndpointWhat it does
SyncwebhookNormalize inbound POS/e-commerce events at the edge.
DecidePOST /v1/pricing/evaluateSolve commission + tax against your net-margin floor.
DefendPOST /v1/pricing/syncPush the calculated price to outbound aggregators.
GovernGET /v1/audit/ledgerRetrieve the signed, bilingual compliance log.
Conventions All requests and responses are application/json unless noted. Monetary values are sent as integer minor units (e.g. 5000 = QAR 50.00) to avoid floating-point drift. Timestamps are RFC 3339 UTC. Every response carries an x-prizeskout-request-id header — include it in support tickets.

JOURNEY B

Cryptographic Webhook Verification

When Salla, Zid, or Foodics changes a product, PrizeSkout normalizes the event and forwards it to your endpoint. Every delivery is signed with an HMAC-SHA256 signature over the raw request body. Verify it before trusting a single byte.

HeaderExamplePurpose
prizeskout-signaturet=1719580800,v1=4f8b…Timestamp + hex HMAC. Compare in constant time.
prizeskout-eventproduct.price.updatedEvent type for routing.
prizeskout-deliveryevt_3xZ…Idempotency key — dedupe on this.
Critical You must compute the HMAC over the raw body bytes, before any JSON parser or body-middleware mutates them. Re-serializing parsed JSON will change whitespace and key order, and the signature will never match. 
import express from "express";
import crypto from "node:crypto";

const app = express();
const SECRET = process.env.PRIZESKOUT_WEBHOOK_SECRET!; // whsec_...
const TOLERANCE = 300; // reject events older than 5 min (replay defense)

// IMPORTANT: capture the RAW body, not a parsed object.
app.post(
  "/webhooks/prizeskout",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const header = req.headers["prizeskout-signature"] as string;
    if (!header) return res.status(400).send("missing signature");

    // header looks like: "t=1719580800,v1=4f8b..."
    const parts = Object.fromEntries(header.split(",").map((p) => p.split("=")));
    const timestamp = Number(parts.t);
    const signature = parts.v1;

    // 1) Reject stale timestamps.
    const age = Math.floor(Date.now() / 1000) - timestamp;
    if (Number.isNaN(timestamp) || age > TOLERANCE) {
      return res.status(400).send("timestamp outside tolerance");
    }

    // 2) Recompute HMAC over `${timestamp}.${rawBody}`.
    const signedPayload = `${timestamp}.${req.body.toString("utf8")}`;
    const expected = crypto
      .createHmac("sha256", SECRET)
      .update(signedPayload, "utf8")
      .digest("hex");

    // 3) Constant-time compare to defeat timing attacks.
    const ok =
      signature?.length === expected.length &&
      crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected));
    if (!ok) return res.status(401).send("invalid signature");

    // 4) Safe to parse now.
    try {
      const event = JSON.parse(req.body.toString("utf8"));
      console.log(`verified ${event.type} for sku=${event.data.sku}`);
      // ...enqueue for evaluation (Journey C)
    } catch (err) {
      console.error("malformed json after valid signature:", err);
      return res.status(422).send("unparseable body");
    }

    // Ack fast; do heavy work async.
    res.status(200).send("ok");
  }
);

app.listen(8080, () => console.log("listening on :8080"));
import hashlib, hmac, json, time
from flask import Flask, request, abort

app = Flask(__name__)
SECRET = os.environ["PRIZESKOUT_WEBHOOK_SECRET"].encode()  # whsec_...
TOLERANCE = 300  # reject events older than 5 minutes (replay defense)

@app.route("/webhooks/prizeskout", methods=["POST"])
def handle():
    header = request.headers.get("prizeskout-signature", "")
    if not header:
        abort(400, "missing signature")

    # header looks like: "t=1719580800,v1=4f8b..."
    parts = dict(p.split("=", 1) for p in header.split(","))
    try:
        timestamp = int(parts["t"])
        signature = parts["v1"]
    except (KeyError, ValueError):
        abort(400, "malformed signature header")

    # 1) Reject stale timestamps.
    if int(time.time()) - timestamp > TOLERANCE:
        abort(400, "timestamp outside tolerance")

    # 2) Recompute HMAC over raw bytes: f"{timestamp}.{raw_body}".
    raw = request.get_data()  # bytes, untouched by any parser
    signed_payload = f"{timestamp}.".encode() + raw
    expected = hmac.new(SECRET, signed_payload, hashlib.sha256).hexdigest()

    # 3) Constant-time compare.
    if not hmac.compare_digest(signature, expected):
        abort(401, "invalid signature")

    # 4) Safe to parse now.
    try:
        event = json.loads(raw)
    except json.JSONDecodeError as err:
        app.logger.error("malformed json after valid signature: %s", err)
        abort(422, "unparseable body")

    app.logger.info("verified %s for sku=%s", event["type"], event["data"]["sku"])
    # ...enqueue for evaluation (Journey C)
    return "ok", 200
# PrizeSkout delivers the webhook TO you — cURL here simulates one
# inbound delivery so you can test your verifier locally.

TS=$(date +%s)

JOURNEY C

Programmatic Margin Policy Evaluation

Before publishing anything outbound, ask the engine for the minimum retail floor that protects your target margin after commission and regional tax. This is a pure calculation — no outbound side effects.

POST/v1/pricing/evaluate

The formula

The floor price is derived so that, after the aggregator takes its commission and you reserve your target margin, the base cost and logistics fee are still fully covered:

margin floor
floor = (base_cost + delivery_fee) / (1 – (commission% / 100) – (target_margin% / 100))

regional tax (e.g. KSA VAT 15%) is then applied on top of the floor.

Request body

FieldTypeDescription
sku requiredstringMerchant SKU reference, e.g. QA-BURGER-01.
base_cost requiredintegerCost of goods, minor units (2200 = QAR 22.00).
delivery_fee requiredintegerLogistics fee, minor units.
commission_pct requirednumberAggregator commission, e.g. 25.
target_margin_pct requirednumberNet margin to protect, e.g. 18.
currency requiredstringISO-4217: QAR, SAR, or AED.
tax optionalobjectRegional tax rule, e.g. { "type": "ksa_vat", "rate_pct": 15 }.
// Express route that wraps an evaluate call.
app.post("/internal/quote", express.json(), async (req, res) => {
  try {
    const quote = await client.pricing.evaluate({
      sku: "QA-BURGER-01",
      base_cost: 2200,          // QAR 22.00
      delivery_fee: 650,         // QAR 6.50
      commission_pct: 25,
      target_margin_pct: 18,
      currency: "QAR",
      tax: { type: "qa_none", rate_pct: 0 }, // Qatar: 0%
    });

    console.log(`floor for ${quote.sku}: ${quote.floor_price.display}`);
    res.json(quote);
  } catch (err: any) {
    // 422 = policy can't be satisfied (commission + margin >= 100%)
    if (err.status === 422) {
      return res.status(422).json({ error: err.code, hint: err.message });
    }
    console.error("evaluate failed:", err.message);
    res.status(500).json({ error: "internal_error" });
  }
});

JOURNEY D

Dynamic Outbound Push (The Reprice Loop)

Commit a calculated price to one or more aggregators in a single call. The platform fans out to each target, paces the outbound traffic, and returns per-aggregator results inside the sub-1.85 second budget.

POST/v1/pricing/sync
FieldTypeDescription
sku requiredstringSKU to reprice.
price requiredintegerNew price in minor units (use the evaluated floor).
currency requiredstringQAR · SAR · AED.
aggregators requiredstring[]Target IDs, e.g. ["talabat_qa","jahez_sa"].
idempotency_key optionalstringSafe-retry token. Reuse to avoid double-pushes.
Rate limits The sync endpoint is capped per merchant. On 429, honor the Retry-After header and back off exponentially. The examples below implement bounded exponential backoff with jitter — never a tight retry loop. 
import { randomUUID } from "node:crypto";

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

async function repriceWithBackoff(maxRetries = 4) {
  const idempotencyKey = randomUUID();

  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      const result = await client.pricing.sync({
        sku: "QA-BURGER-01",
        price: 5000,                 // QAR 50.00 (from evaluate)
        currency: "QAR",
        aggregators: ["talabat_qa", "jahez_sa"],
        idempotency_key: idempotencyKey, // stable across retries
      });
      console.log(`committed in ${result.latency_ms}ms`, result.results);
      return result;
    } catch (err: any) {
      if (err.status === 429 && attempt < maxRetries) {
        // Respect Retry-After; otherwise exponential backoff + jitter.
        const retryAfter = Number(err.headers?.["retry-after"]) || 0;
        const backoff = retryAfter * 1000 || Math.min(2 ** attempt * 200, 3000);
        const jitter = Math.random() * 120;
        console.warn(`429 → retry ${attempt + 1} in ${Math.round(backoff + jitter)}ms`);
        await sleep(backoff + jitter);
        continue;
      }
      console.error(`sync failed (status ${err.status}):`, err.message);
      throw err; // non-retryable, or retries exhausted
    }
  }
}
repriceWithBackoff();
import random, time, uuid
from prizeskout import PrizeskoutError

def reprice_with_backoff(max_retries: int = 4):
    idempotency_key = str(uuid.uuid4())

    for attempt in range(max_retries + 1):
        try:
            result = client.pricing.sync(
                sku="QA-BURGER-01",
                price=5000,                 # QAR 50.00 (from evaluate)
                currency="QAR",
                aggregators=["talabat_qa", "jahez_sa"],
                idempotency_key=idempotency_key,  # stable across retries
            )
            print(f"committed in {result.latency_ms}ms", result.results)
            return result

        except PrizeskoutError as err:
            if err.status == 429 and attempt < max_retries:
                # Respect Retry-After; else exponential backoff + jitter.
                retry_after = float(err.headers.get("retry-after", 0))
                backoff = retry_after or min(2 ** attempt * 0.2, 3.0)
                jitter = random.uniform(0, 0.12)
                print(f"429 → retry {attempt + 1} in {backoff + jitter:.2f}s")
                time.sleep(backoff + jitter)
                continue
            print(f"sync failed (status {err.status}): {err}")
            raise  # non-retryable, or retries exhausted

Errors & Rate Limits

PrizeSkout uses conventional HTTP status codes. 2xx means success; 4xx indicates a problem with the request; 5xx indicates a platform error (rare, and safe to retry idempotently).

StatusCodeMeaning & action
400invalid_requestMalformed body or missing field. Do not retry without fixing.
401invalid_signatureBad key or webhook signature. Check secret & raw-body handling.
422unsatisfiable_policycommission% + margin% ≥ 100. Adjust inputs; floor is undefined.
429rate_limitedBack off using Retry-After + exponential delay.
503aggregator_unavailableDownstream network down. Retry idempotently with backoff.
